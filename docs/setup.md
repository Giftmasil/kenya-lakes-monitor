## How to do your first PR

1. Accept the GitHub invite (check your email or github.com/notifications).
2. In GitHub Desktop: **File → Clone repository** → `Giftmasil/kenya-lakes-monitor`.
3. **Current branch → New branch**, named `setup/<your-first-name>` (e.g. `setup/juliet`).
4. Create your virtual environment and install requirements (see README → Getting started).
5. Fill in your row in this file with ✅ for each step that works (leave Earth Engine blank for now).
6. Commit, click **Publish branch**, then **Create Pull Request**.
7. Ask your review partner to review it. Once approved, click **Squash and merge** on GitHub.
